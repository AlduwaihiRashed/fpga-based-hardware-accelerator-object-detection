# FPGA-Based Hardware Accelerator for Real-Time Object Detection

Senior Design Project (CMP/COE 490–491), American University of Sharjah, Fall 2026.

YOLOv3-Tiny on the AMD Kria KV260. The FPGA runs the network layers and the ARM CPU handles resize, box decoding and NMS. The research question is **Posit8 vs INT8**: each format is built with post-training quantization (PTQ) and quantization-aware training (QAT), and compared against a Float32 baseline on accuracy, speed, power and FPGA resources.

**Team:** Rashed Alduwaihy (team leader, system integration), Ahmed Almash (FPGA hardware architecture), Shaden Alghamdi (AI and software), Joud Almutairi (FPGA implementation and verification).
**Advisors:** Dr. Muhammad Imran, Dr. Omar Arif.

## Setup

| Item | Value |
|---|---|
| Model | YOLOv3-Tiny, Leaky ReLU slope 0.1, 6 k-means anchors |
| Dataset | PASCAL VOC, 20 classes. Train on VOC07+12 trainval (90/10 train/val split), test on VOC2007 test (4,952 images) |
| Input | Fixed 320×320 letterbox |
| Metric | mAP@0.5, 11-point (official) and all-point. NMS IoU 0.45 |
| Board | AMD Kria KV260 (Vitis HLS + Vivado) |
| Targets | mAP within 5 points of Float32, INT8 at ≥ 15 FPS (30 desired), board power ≤ 12 W, 30 min on a 12 V battery |

## Running the software

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cd software

python anchors.py                                                    # k-means anchors (already in config.py)
python train.py --name float32-v2                                    # Float32 training from darknet COCO weights
python test_report.py ../data/runs/float32-v2/best.pt               # official Float32 test + records
python export_onnx.py ../data/runs/float32-v2/best.pt               # Float32 ONNX for the ARM baseline

python yolov3_tiny_int8.py ../data/runs/float32-v2/best.pt --name int8-ptq   # INT8 calibration (PTQ)
python golden_int8.py ../data/runs/int8-ptq --map val                        # official INT8 mAP
python golden_int8.py ../data/runs/int8-ptq --check 16                       # golden vs fake-quant, layer by layer
```

All paths default to this repo's `data/` folder. To keep data elsewhere (for example on Colab), set `SENIOR_DATA` to a folder with the same layout.

## INT8 arithmetic (matches the hardware)

Symmetric quantization, per-channel weight scales and per-tensor activation scales chosen by MSE on 512 calibration images, round ties-to-even, INT32 accumulation, requantization with a fixed-point multiplier and shift, Leaky ReLU as `x * 6554 >> 16`, and a shared scale at the concat. `software/golden_int8.py` is the bit-exact reference the HLS testbench is checked against.
